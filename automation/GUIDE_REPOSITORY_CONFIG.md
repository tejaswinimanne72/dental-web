# 📖 Enterprise Android Appium Framework - Repository Configuration Guide

## 1. Enabling GitHub Pages
1. Go to your GitHub Repository -> **Settings** -> **Pages**.
2. Source: **Deploy from a branch**.
3. Branch: **`gh-pages`** / Folder: **`/ (root)`**.
4. Click **Save**.

## 2. Live GitHub Pages Report URL
After deployment, your live report dashboard is published at:
`https://<github-username>.github.io/<repository-name>/reports/latest/execution-report.html`
